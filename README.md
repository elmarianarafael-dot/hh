# Patadas Survivor — versión 3

Juego web de supervivencia con 13 personajes, habilidades diferenciadas, mapa procedural infinito, oleadas progresivas y mejoras.

## Novedades
- Enemigos escolares: lápices, libros, borradores, reglas, mochilas y cuadernos.
- Cada 5 oleadas aparece un jefe escolar gigante (libros).
- Al derrotarlo recibes 250 monedas, experiencia y recuperación de vida.
- Evolución de habilidad: al conseguir nivel 5 de daño y al menos nivel 3 de área o cantidad, tu habilidad principal evoluciona y hace 80% más daño.
- Mapa verde procedural con árboles y arbustos.

## Publicar en GitHub Pages
Sube `index.html`, `README.md` y la carpeta `assets` completa a la raíz del repositorio. En Settings > Pages selecciona `Deploy from a branch`, rama `main`, carpeta `/ (root)`.

## Controles
- PC: WASD o flechas.
- Tablet: botones de dirección.
- El ataque es automático.
- Recoge gemas de experiencia y monedas.
- El progreso se guarda localmente en el navegador.
